# Trước bài đầu tiên / Before your first lesson

## Tiếng Việt

Bạn cần máy tính có Python 3 và một trình soạn thảo. Các bài này không cần cài thêm thư viện. Có thể dùng trình soạn thảo bạn đã quen; trên máy có IDLE, mở file rồi chọn Run → Run Module. Trong terminal, chạy `python starter.py`; một số máy Windows dùng `py starter.py`, một số máy khác dùng `python3 starter.py`.

1. Mở thư mục của đúng bài học.
2. Sao chép `starter.py` thành `my-work.py` và sửa bản sao.
3. Chạy `my-work.py`. Khi chương trình hỏi, gõ câu trả lời ở terminal rồi nhấn Enter.
4. Đọc `STUDENT.md`, tự làm thử, rồi mới xem gợi ý và `solution.py`.
5. Khi hỏi hỗ trợ, gửi số bài, đoạn code ngắn, kết quả bạn mong muốn và lỗi thực tế. Không gửi mật khẩu hay dữ liệu cá nhân.

Nếu máy báo không tìm thấy Python, nhờ người hỗ trợ cài Python 3 từ [python.org](https://www.python.org/downloads/), rồi mở lại terminal. Nếu báo không tìm thấy file, kiểm tra terminal đang ở thư mục nào. Nếu không hiện gì, kiểm tra bạn đã lưu file và đang chạy đúng bản.

Các ví dụ dùng chữ không dấu trong terminal để dễ chạy trên nhiều máy; phần hướng dẫn dùng tiếng Việt đầy đủ. Bạn có thể đổi nội dung hiển thị. Tên biến trong Python phải giữ đúng khi bạn sử dụng lại.

Mỗi bài: xem một đoạn → đoán kết quả → chạy thử → thay đổi → giải thích. Không cần gõ nhanh. Khi bị kẹt, giảm bài toán xuống một đầu vào nhỏ nhất mà vẫn gây lỗi.

## English

Use a computer with Python 3 and a text editor. No third-party packages are required. Copy the lesson's `starter.py` to `my-work.py`, edit the copy, and run it from that folder with `python my-work.py` (or `py` / `python3` on your system). Type answers in the terminal when asked. Read `STUDENT.md` before checking the hints and reference solution.

Lessons 09 and 10 create `books.json` beside the running script. Use separate folders when you want separate projects. This program runs on one computer; it is not an online library shared by multiple users.
